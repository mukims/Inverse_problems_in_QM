# nb/ — Exploratory notebooks

Where ideas were worked out before becoming scripts. Useful for understanding *how* a
model was arrived at; **not** the place to run production training — use the scripts in
the sibling folders for that.

---

## Notebooks

| Notebook | Topic |
|---|---|
| `misfit_agnr.ipynb` | Original misfit-based concentration analysis. The ancestor of `concentration/pinn_agnr.py`. |
| `xgb.ipynb` | XGBoost exploration with Optuna tuning, over both raw curves and engineered features (band-edge onset, spectral variance, mean suppression). |
| `compare_analysis.ipynb` | Four-way comparison write-up. Generated by `concentration/create_notebook.py`. |
| `inverse_design.ipynb` | Distance-matrix inverse design. Pairs with [`../defect_reconstruction/`](../defect_reconstruction/). |
| `test_forward_model.ipynb` | Exercises the surrogate forward model. |
| `test_validation_pinn_agnr.ipynb` | PINN test & validation walkthrough. |
| `agnr_leads.ipynb` | Lead construction and Sancho–Rubio decimation experiments. |
| `test.ipynb` | Scratch notebook. Notably where the corrected pristine files (`7_agnr_pris.npy`, `9_agnr_pris.npy`) were regenerated after a band-gap scaling bug. |

## Checkpoints here

`agnr_autoencoder.pt` and `agnr_checkpoint_encoder.pt` are produced/consumed by the
notebooks (autoencoder experiments in `test.ipynb`), which is why they live here rather
than with the script-driven models.

## ⚠️ Imports after the reorganisation

These notebooks were written when every script sat in one flat directory, so they do
things like `import pinn_agnr_curvature` or `import forward_model`. **Those modules now
live in sibling folders and will not import as-is.**

Add this as the first cell of any notebook you reopen:

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path.cwd().parent))
import _bootstrap  # puts physics/, concentration/, defect_reconstruction/, ... on sys.path
```

Then the original `import` lines work unchanged.

Which notebooks need it:

| Notebook | Imports |
|---|---|
| `compare_analysis.ipynb` | `pinn_agnr_curvature` → `../concentration/` |
| `inverse_design.ipynb` | `inverse_model`, `patched_transformer_model` → `../defect_reconstruction/` |
| `test_forward_model.ipynb` | `forward_model` → `../defect_reconstruction/` |
| `test_validation_pinn_agnr.ipynb` | `ca_agnr` → `../physics/`, `pinn_agnr` → `../concentration/` |

Data paths inside the notebooks may also need one extra `../`, since the notebooks are
now a level deeper. They were left unedited — editing notebook JSON in bulk risks
corrupting outputs, so the fix is applied when you next open one.

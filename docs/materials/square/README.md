# Square strip (`square`, toy model)

An idealised single-orbital square-lattice strip. It plays two roles:
- In the material atlas it is the **unseen lattice**: Shazam is never trained on it, and it must flag it as unknown.
- It is also the system of the older square-10 concentration studies.

Shared conventions (device, leads, store, Shazam input) are in the [materials README](../README.md).

## Physical model

| Item | Value |
|---|---|
| Orbitals | one per site |
| Hopping | nearest neighbour **t = 1**, enters H as −t; on-site 0 |
| Transverse modes (width l) | ε_p = −2t cos(pπ/(l+1)), p = 1 … l. Channel p is open when \|E − ε_p\| < 2t. |
| Band top | 2t + 2t cos(π/(l+1)) = **3.919 t** for l = 10 |
| `t_ev` | **1.0, arbitrary** (toy model) |
| E = 0 | band centre |
| Window | E ≥ 0 |

## Ribbon geometry (`tbribbon.lattices.square_strip(width)`)
- `H0` is a chain of `width` sites with hopping −t between neighbours across the strip.
- `H1 = −t·I`: each site couples to the same site in the next cell.
- The edge label is `strip`; there are **width sites per cell**.
- The device is 100 cells (1,000 sites for N10).

## Transport
- **Legacy trace formula** (`tbribbon.transport._legacy_trace`), device η = 1e-3: `T = |Tr[G̃_LL H1 G̃_RR H1 − H1 G̃nl H1 G̃nl]|` with `G̃ = G − G†`.
- It reproduces `notebooks/square_lattice/ca_sq.py`'s `device()`, so the atlas data is consistent with the older square-10 dataset. The generator allows it only because `H1` is symmetric.
- **Leads:** Sancho–Rubio (`LeadCache`), η = 1e-4.
- **Not bounded:** like graphene armchair, the legacy formula spikes above the channel count at subband edges. In the legacy square-10 data, spikes rise from 1% of inputs at c = 5 to 29% at c = 90.

## Energy grid
Stored on the units-of-t grid: **0–3.99 t, step 0.01 (400 points)**. Shazam's eV axis rescales it with t_ev = 1 and zero-fills above the band top (3.919).

## Disorder

| Item | Value |
|---|---|
| Impurity | on-site +V = 0.5 t on a random site |
| Count | `n_imp = round(d × 1000)` for N10: 5 / 10 / 20 / 40 at 0.5 / 1 / 2 / 4% |
| Placement | `impurity_shifts`, `RandomState(seed).choice` without replacement, nested |
| Seeds | **0–149** per density. It is never trained on, so there is no train/validation/test split. |

## How it is used
- **Unseen-lattice gate:** Shazam must flag at least 99% of the 600 spectra as unknown.
  - v2: 100%, AUROC 0.9998;
  - v3: 100%;
  - v4: 100%, AUROC 0.9999.
- **BUILD-18 (meaning embedding):** the "unseen" group whose graded similarity the embeddings are tested on.

## Reproduce
`notebooks/material_atlas/eval_novelty.py` generates the strip on first use (`generate(store, [square N10], [0.005, 0.01, 0.02, 0.04], InputSpec(v2), formula="legacy_trace", seeds=range(150))`). Equivalently:

```bash
PYTHONPATH=notebooks/material_atlas:notebooks ~/miniconda3/envs/ml/bin/python - <<'EOF'
from atlaslib import CloudStore, InputSpec
from tbribbon.generate_clouds import generate
from tbribbon.materials import make_model
generate(CloudStore("~/atlas_store/novelty_v1"), [make_model("square", "strip", 10)], [0.005, 0.01, 0.02, 0.04],
         InputSpec(version="v2"), n_jobs=4, formula="legacy_trace", seeds=range(150))
EOF
```

## Caveats
- **Arbitrary energy scale** (t_ev = 1). On the eV axis its band ends at 3.92, between MoS₂ / triangular (about 2.7–3) and the graphene family (about 7–8 eV).
- **Different transport formula:** it uses the legacy trace formula, not Caroli as the new materials do. Its spikes are part of what makes it look "unknown", alongside its lattice.
